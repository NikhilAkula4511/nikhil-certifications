## Add your certificate files

Copy PDF or PNG into the matching folder, then:

```bash
cd ~/Projects/nikhil-github-portfolio
bash push_certifications.sh
```

Accepted names: `certificate.pdf`, `certificate.png`, `badge.png`, or any `*.pdf` / `*.png`.
